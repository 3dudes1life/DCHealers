DC HEALERS — PREMIUM UX UPDATE v12

WHAT THIS DOES
- Fixes the excessive eyebrow/header letter spacing.
- Refines the hero proportions, typography and vertical rhythm.
- Gives the navigation, buttons, cards, forms and FAQs a premium feel.
- Adds subtle motion and tactile hover/press states.
- Redesigns spacing and sizing for mobile instead of simply shrinking desktop.
- Keeps the current colors, content, theme, links and Reiki vibe.

EASIEST INSTALL ON A MAC
1. Download your DCHealers repository from GitHub and unzip it.
2. Copy all three files from this update folder into the main DCHealers folder,
   beside index.html and style.css.
3. Double-click apply-premium.command.
4. Upload the changed repository files to GitHub.
5. Wait for GitHub Pages to deploy, then hard-refresh the website.

MANUAL INSTALL
1. Open dc-premium-ux.css.
2. Copy everything and paste it at the very bottom of the existing style.css.
3. In every HTML file, change /style.css?v=11 to /style.css?v=12.

ROLLBACK
Replace style.css with style.backup-before-premium.css, then change v=12 back
in the HTML stylesheet link if needed.
