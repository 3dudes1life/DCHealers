DC HEALERS CLIENT INTAKE SETUP

1. Open the DC Healers intake spreadsheet while signed into Daniel's Google account.
2. In the spreadsheet, click Extensions > Apps Script. This binds the script to the correct sheet.
3. Delete EVERYTHING currently in the editor and paste the entire contents of DC-Healers-Google-Apps-Script.gs.
4. Click Save.
5. Because a deployment already exists, click Deploy > Manage deployments > Edit (pencil).
6. Under Version, choose New version, then click Deploy.
7. Execute as must be Me, and Who has access must be Anyone.
8. Approve the spreadsheet and email permissions if Google asks.
9. Keep the same /exec URL. Do not create a second deployment unless the existing deployment is missing.
10. Upload the complete DCHealers-main folder to GitHub.
11. Submit one harmless test intake and confirm BOTH a new row in Intake Responses and a complete email to daniel.castaneda@dchealers.com.

FOR A BRAND-NEW DEPLOYMENT ONLY
4. Click Deploy > New deployment.
5. Select Web app, Execute as: Me, and Who has access: Anyone.
6. Deploy and authorize access to the spreadsheet and email notification.
7. The current Daniel-owned /exec URL is already installed in both client-intake.js and client-intake.html.

UPDATING AN EXISTING DEPLOYMENT
After changing the Apps Script, click Deploy > Manage deployments > Edit (pencil) > Version: New version > Deploy. Saving code alone does not update the live web app.

IMPORTANT: Do not put completed client responses in GitHub. The website itself stores no responses.
